# Spartan iOS Release Notes

## 1.1.1

- Redesigned Ladder, rank cards and profile; new rank badges.
- View Stats opens a full stats page for any profile.
- Fixes: all posts load on long profiles, logged-food edits save, deleting a food targets the right day, rank and totals are recorded at workout finish, clearer chart axes, rest-timer notification timing.
- Leaderboards (Compete tab) and direct messages are hidden in this version.

## 1.0.1

- First maintenance release after 1.0 focused on stability and polish.
- Fixes the leaderboard rank refresh flow so standings stay in sync.
- Cleans up a few UI regressions spotted in the feed right after launch.
